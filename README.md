# Reverie

一款基于 Electron + React 的桌面音乐播放器。

## 功能

- 扫码登录，登录态保存在本地
- 歌曲搜索、排行榜、每日推荐、漫游、我的歌单
- 播放控制：播放/暂停、上一首/下一首、进度、音量、播放模式
- 播放页：封面 + 歌词（卡拉 OK 高亮、歌词主题、译文、字号）
- 主题：跟随系统 / 浅色 / 深色
- 最近播放与播放队列保存在本地，重启后恢复
- 启动时自动检查更新，有新版本弹窗提示
- 设置中包含关于、隐私说明与免责声明

## 安装

### 安装地址

- 安装包下载地址：http://tk25wzhbq.hd-bkt.clouddn.com（国内镜像，主用）
- 备用下载：https://github.com/Tenth-G/Reverie/releases
- 安装版（`Reverie-Setup-<版本>-x64.exe`）：下载后双击运行，按向导完成安装
- 便携版（`Reverie-Portable-<版本>-x64.exe`）：免安装，下载后直接运行

### 从源码运行

需要 Node.js 22.12 及以上。

```bash
npm install      # 安装依赖
npm run dev      # 开发模式（热更新）
npm start        # 构建并运行
```
